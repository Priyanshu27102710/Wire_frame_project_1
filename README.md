# Personal Portfolio Website

## 📌 Project Overview

Live URL: https://priyanshuwireframe2710.netlify.app/

This project is a **Personal Portfolio Website/Wireframe** created using **HTML and CSS**.
The website presents personal information, skills, projects, education, certified courses, and contact details in a simple portfolio layout.

## 🛠️ Technologies Used

* CSS3

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder in **VS Code**.
3. Make sure the `Image` folder is in the same folder as the HTML file.
4. Open `Project_wireframe.html`.
5. Right-click on the file and select **Open with Live Server**.

Or simply open the `.html` file directly in a web browser.
